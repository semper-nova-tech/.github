# Semper Nova AI

Welcome to Semper Nova AI.ss

Explore our OSS skills and tools as we build for the AI era.

## Projects

### [Pallas Skema](https://github.com/semper-nova-tech/pallas-skema)

An agent-native diagramming solution. The diagram, the renderer, the skill, and a optional TUI to edit gives you an SVG, PNG, or GIF for 
motion enabled diagrams.


### [Pallas Agent Flow](https://github.com/semper-nova-tech/pallas-agent-flow)

A portable, skills-only workflow plugin to take requirements, for a coherent PRD, design, sequence, adversarial review and implementation.
Supports Claude and Cursor but works with other agents via the skills.

### [Pallas TS Skills](https://github.com/semper-nova-tech/pallas-ts-skills)

Portable agent instructions for my opinionated starter stack.s TypeScript, Angular, Hapi, and Drizzle: `AGENTS.md`, Cursor rules, and reusable skills. 
Install them into a target repository so the guidance is versioned with the code.

### [Pallas Herdr skills](https://github.com/semper-nova-tech/pallas-herdr-cli-skills)

Skills for [Herdr](https://herdr.dev), a terminal multiplexer for coding agents.

- **cli-herdr** inspects and controls workspaces, tabs, panes, and agents.
- **cli-hunk** drives a live Hunk diff-review session.
- **pallas-glow** opens markdown in Glow as a read-only pane.
- **pallas-ttt** opens a source file in the TTT editor pane.

### [Jester](https://github.com/semper-nova-tech/jester-ai)

A decision model for AI. The repository is public and the model is still early.
